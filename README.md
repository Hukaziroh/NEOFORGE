# NEOFORGE

## 프로젝트 개요
NEOFORGE는 Unity 엔진을 기반으로 개발된 공장 자동화(Automated Factory) 시뮬레이션 프로젝트입니다. 자원 채굴, 가공기 배치, 그리고 자동화 생산 라인 구축을 핵심 메커니즘으로 하고 있으며, 포트폴리오 목적으로 구성된 공식 리포지토리입니다.

## 주요 시스템 및 기능
* 공장 자동화 시스템: 자원 가공기 배치 및 생산 자동화 파이프라인 구현
* 청크(Chunk) 시스템: 효율적인 맵 데이터 생성 및 월드 로드 처리
* 1인칭(FPS) 컨트롤: 1인칭 시점을 통한 직관적인 오브젝트 상호작용 및 환경 탐색
* 데이터 직렬화: JSON을 활용한 게임 상태 저장, 불러오기 및 설정 데이터 관리
* 튜토리얼 시스템: 플레이어의 진행 상황과 작동 방식에 맞춘 인게임 튜토리얼

## 개발 환경
* Engine: Unity
* Language: C#
* Graphics: Universal Render Pipeline (URP)
* Version Control: Git / GitHub
